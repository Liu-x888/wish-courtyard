# 愿庭 · Wish Courtyard

一座虚构中式庭院中的桌面浏览器第一人称漫游与情绪记录游戏。项目使用 Vite、React、TypeScript 与 Three.js 构建。

所有礼佛、上香、财神和还愿内容均为游戏化文化演出，不提供真实宗教服务，不承诺愿望结果，不包含支付或功德收费。

## 本版升级

- 使用程序化曲面屋顶、屋脊吻兽、实例化瓦当与斗拱重建立体建筑。
- 主殿采用台基、踏步、五开间立面、花格门窗、匾额、帷幔、铜制静心装置与室内灯光。
- 庭院加入许愿树、石池锦鲤、香炉烟、石灯、竹丛、经幡、铺装与远景山体。
- 男女角色使用分层低模结构，包含袍服、束带、发型、四肢和行走摆动。
- 支持 WASD 移动、鼠标视角、`E` 交互、`V` 第一/第三人称切换、Shift 快走。
- 楼梯使用连续斜坡高度采样与轴分离碰撞，不依赖完整物理引擎。
- 许愿签和心绪记录仅保存在浏览器本机。

## 运行

```powershell
npm install
npm run dev
```

生产构建：

```powershell
npm run check
npm run build
npm run preview
```

浏览器视觉回归：

```powershell
npm run visual-check
```

视觉回归默认调用 Windows 上的 Microsoft Edge，并复用 Playwright Core；其他系统需要修改 `scripts/visual-check.mjs` 中的 `executablePath`。

## 验收步骤

1. 打开页面，选择“青裳”或“玄衣”，点击“踏入愿庭”。
2. 使用 WASD 行走，移动鼠标观察庭院，按住 Shift 快走。
3. 按 `V` 检查第一与第三人称；第三人称应显示行走摆臂和腿部动作。
4. 从山门沿中轴前行，在主殿台阶上验证连续升高与碰撞。
5. 靠近香炉、许愿树、许愿池、左右厢房或主殿，检查金色交互标记与底部提示。
6. 按 `E` 打开对应交互，完成保存、浏览或静心流程；数据不会上传。

## 项目结构

- `src/game/world.ts`：庭院布局、建筑、植被、水景、灯光动画与碰撞数据。
- `src/game/modeling.ts`：曲面屋顶、斗拱、花格、匾额、树木等程序化建模部件。
- `src/game/characters.ts`：男女角色低模分层、材质和行走动画。
- `src/game/WishCourtyardGame.ts`：第一/第三人称控制、斜坡移动、交互检测与渲染循环。
- `src/App.tsx`：开始界面、HUD、交互弹窗和本机记录工具。
- `src/styles.css`：响应式视觉与动效。

## 已知限制

- 场景为程序化低模艺术风格，不是 3A/4A 写实资产管线，未包含骨骼动画、动作捕捉或全局光照烘焙。
- 第三人称镜头没有完整的墙体遮挡回缩逻辑。
- 交互以距离判定为主，没有逐像素拾取。
- 移动端仅提供基础响应式界面，核心体验以桌面键鼠为准。
- 项目无后端，所有记录只保存在本机 `localStorage`。
